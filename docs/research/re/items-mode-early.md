# ItemMode server helpers, first remaining range

Static trace of all 26 ITEMS/ItemMode.cpp functions below `0055f000` that
were cited or untouched in the gap map generated at source `1265c32d`.
Evidence read: the local stock 1.14d Ghidra export `game_all.c`, with the
matching `research/game114d.asm` instruction listing checked for register
arguments, stack cleanup, dispatch and no-op bodies. These are static
observations unless a later oracle is explicitly named below; they are not
claims of d2d runtime parity.

The decompiler loses register arguments. In particular `FUN_0055bff0`
takes the item in ESI; `FUN_0055c070`/`FUN_0055c110` take item in EAX and
player in EDI; `FUN_0055c470` takes owner in EAX and output pointers in EBX
and EDI. Assertions terminate through the common fatal path; they are not
ordinary failure returns.

Remaining unknowns are deliberately bounded: helper return/status meanings
are retained numerically where no semantic name was established; the empty
grid/belt helpers add no effects. Inventory unlink is real through `FUN_0063ad90`/`FUN_0063aaf0`; belt placement `FUN_0063c4f0` checks Beltable and 1x1 dimensions, then `FUN_0063c4c0` calls `FUN_0063afd0` to unlink/relink and update coordinates. The compaction caller ignores placement failure. No gameplay
correction is proposed by this trace, and no original/port runtime comparison
was performed.
